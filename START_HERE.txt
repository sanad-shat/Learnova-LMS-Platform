EDUSPHERE LMS — FINAL UPGRADED VERSION

FASTEST START ON WINDOWS
1. Open: projectPy27\ecms
2. Double-click: start_windows.bat
3. Open: http://127.0.0.1:5000/

MANUAL START IN VS CODE
1. Open the folder projectPy27\ecms (not projectPy27 only).
2. Open Terminal and run:
   python -m venv venv
   venv\Scripts\activate
   python -m pip install -r requirements.txt
   python run.py
3. Open http://127.0.0.1:5000/
