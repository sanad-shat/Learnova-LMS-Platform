# Learnova LMS

## Overview
Learnova LMS is a web-based Learning Management System developed using Python and Flask. The system provides tools for managing courses, quizzes, certificates, and student progress.

## Features
- Student Portal
- Teacher Portal
- Quiz and Exam Builder
- Student Progress Tracking
- Certificate Generation
- User Authentication
- Dashboard

## Technologies
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Installation

```bash
pip install -r requirements.txt
```

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/sanad-shat/Learnova-LMS.git
```

2. Navigate to the project folder:

```bash
cd Learnova-LMS
```

3. Install the required packages:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python vv.py
```
