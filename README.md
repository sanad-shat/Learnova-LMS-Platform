# Learnova LMS

## Overview
Learnova LMS is a web-based Learning Management System developed using Python and Flask. The system provides tools for managing courses, quizzes, certificates, and student progress.

## Features
- Student Portal
- Teacher Portal
- Quiz and Exam Builder
- Student Progress Tracking
- Certificate Generation
- User Authentication
- Dashboard

## Technologies
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Installation

```bash
pip install -r requirements.txt
python vv.py
```
